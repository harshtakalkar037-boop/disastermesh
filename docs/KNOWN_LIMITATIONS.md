# Known limitations

Honest limits of this prototype. None of these are hidden successes.

## Not verified on hardware

- BLE advertise, scan, connect, and GATT write were not executed on a phone here. The code calls the platform APIs and surfaces errors. Multi-hop is UNVERIFIED.
- The GATT client now fragments a packet and does not mark it relayed until every fragment write returns and a confirmation read matches complete reassembly plus a valid signature. That path is compiled. It was not executed on a phone. A partial GATT write is still not delivery. Physical multi-hop remains UNVERIFIED.
- Wi-Fi Direct discovery, connect, and socket exchange exist as an adapter and were not run. Group-owner IPv4 `192.168.49.1` is a known conflict; the code does not assume that address.
- Wi-Fi Aware is probed only.
- iQOO and other OEM battery managers can kill scans. That has not been measured here.
- Speech recognition depends on the device. If it fails, the UI says to type. No transcript is invented.
- Image tagging returns unavailable. There is no on-device vision model in this build.
- A debug APK was built here (`artifacts/disastermesh-debug.apk`). It was not installed on a phone. See `docs/IMPLEMENTATION_STATUS.md`.

## Product limits

- No certified rescue, no delivery guarantee, no coverage map.
- SAFE is a self-report. Unknown is the default. Silence is never turned into safe.
- Official alerts are not generated by the extractor. There is no SACHET or other government feed adapter beyond `UnconfiguredOfficialFeed`.
- Grouping uses a conservative GPS rule. It does not use BLE RSSI as proof people are together.
- The scale simulator does not apply per-packet signatures. Protocol tests do. Simulator numbers are logical ticks.
- Local demo may use HTTP and PGlite. Production should use TLS and PostgreSQL. JWT in this demo is a bearer token, not a hardened session cookie.
- Responder navigation opens an installed map app. It does not draw a turn-by-turn route itself.
- Some diagnostic mesh errors are English even when the primary UI is Hindi or Marathi.
