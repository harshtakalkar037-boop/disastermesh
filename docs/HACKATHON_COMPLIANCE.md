# Hackathon compliance

Checked on **2026-09-27** against the public guide at <https://iqoo.reskilll.com/guide>.

## Rule that matters

The published build rules say:

> Original work only: code written during the event window. No shipping a pre-built product.
>
> Open-source libraries and frameworks are fine with attribution; carrying in a completed app is not.

Organisers may verify that a project was built inside the event window. Cheating, plagiarism, or unfair practice means disqualification. Participants retain IP, and the organisers receive a showcase licence. See also <https://iqoo.reskilll.com/terms>.
